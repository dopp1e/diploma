\subsection{User Settings}
\label{sec:PlannedSettings}

The application's current implementation is very much guilty of using "magic numbers" \cite{martinCleanCodeHandbook2009} with no way to adjust them.
Be it the angle margin for slot connection detection, the sizes of components, or the colors used for the hands and their highlights, the values for them are set in stone, with no way for a user to adjust them to their liking.

Introducing a menu for adjusting these, and other, settings would greatly increase accessibility and user comfort.
For example, allowing a user to adjust the colors used for the hands and their highlights could help those with color blindness better perceive the hands' positions and states.
Similarly, allowing users to adjust the angle margin for slot connection detection could help those with less precise hand movements have an easier time connecting components.
Other settings that could be adjusted include audio volume levels and the previously mentioned slot scale multiplier.
This list is by no means exhaustive, and further settings could be added based on user feedback and testing.
