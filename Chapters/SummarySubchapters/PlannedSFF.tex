\subsection{Wider Component Variety (Jakub Jędrzejczyk)}

The current version of the application includes a very limited selection of components that can be used to build a computer system.
As no system to automatically aid the user in selecting compatible components, the only incompatibility issues a user faces are currently related to motherboard CPU socket types (LGA 1751, AM5) and RAM types (DDR4, DDR5).
