\subsection{Wider Component Variety (Jakub Jędrzejczyk)}

The current version of the application includes a very limited selection of components that can be used to build a computer system.
As no system to automatically aid the user in selecting compatible components, the only incompatibility issues a user faces are currently related to motherboard CPU socket types (LGA 1151, AM5) and RAM types (DDR4, DDR5), as well as available drives (2.5" or 3.5" SATA drives) and what cases they can fit in.
This poses very little consequence in the context of component choice, requiring very little, if any, planning from the user, as the components are otherwise compatible with each other, be it in regard to power requirements, form factors, or thermal design power (TDP).

By expanding the variety of components available in the application, a more accurate simulation of the PC building process can be achieved, including the need to plan component choices (often in many aspects) ahead of time to ensure compatibility.
This would involve creating additional components, such as motherboards with different socket types (e.g., LGA 1200, AM4), various CPU models with differing TDPs, a wider range of RAM types and speeds, multiple GPU models with varying power requirements, and different PSU wattages.
Additionally, cases with different form factors (ATX, Micro-ATX, Mini-ITX) could be introduced to further complicate component selection.

Lastly, this would require a rework of both the task list system and the validation system to account for the increased complexity of component compatibility.
Rather than use a pre-generated list of tasks, the task list would need to be generated dynamically based on the components selected by the user at throughout the process.
This could also extend to including certain component descriptions in the task list to better inform the user about the specific details of the components they are working with, improving the current, rather vague, descriptions such as "Install the CPU" to something more informative, like "Install the Intel Core i7-10700K CPU into the LGA 1200 socket on the ASUS ROG STRIX Z490-E GAMING motherboard."
